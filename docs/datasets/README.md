# 岭讯知行模拟参考通知数据集 v1

> **数据性质：SIMULATED_REFERENCE（模拟参考）**
>
> 本目录中的通知全部由项目组按常见校园通知格式人工编写，用于开发期回归测试和评测工具联调。它们**不是韶关学院或任何真实单位的正式通知**，不能作为真实校方事实、真实实验结论或生产标注依据，也不得在参赛材料中描述为“真实采集数据”。

## 文件

- `lingxun-simulated-reference-v1.json`：10 条模拟样本，其中 SIM-010 与 SIM-001 构成同一事项的改期版本对，用于验证变更影响。

## 标注字段

`expectedFields` 中每个条目：

| 字段 | 含义 |
| --- | --- |
| `key` | `role/stage/type`，例如 `学生/竞赛报名/截止` |
| `value` | 人工编写的期望归一化值；日期为 `YYYY-MM-DD`，带时间为 `YYYY-MM-DDTHH:mm` |
| `quote` | 期望证据所在的原文片段，必须能在对应 `snapshot` 中逐字找到 |

`expectedUncertain` 表示该样本中**不允许自动确认**的字段；具体原因写在 `reason`。这类字段可用于检查系统的“无依据输出比例”和“不确定字段误确认率”。

## 使用边界

- 真实实验与模拟实验必须分开报告。若评测工具运行在本数据集上，结果只能标记为 `SIMULATED_REFERENCE`，不能写成真实通知上的准确率。
- 数据集是人工构造的，分布不能代表真实校方通知；真实数据到位后应另建带版本号的真实标注集，并保留标注人、标注时间和复核记录。
- 样本中的 `https://example.edu/...` 均为占位地址，不指向真实可访问资源。
