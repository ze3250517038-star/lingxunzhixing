# 课程表：学期起止、周次与单双周

本轮在原有个人课表上增加了“学期设置”和单双周规则。目标不是把课表做成一张静态表，而是让同一门课能按真实学期周次出现，并让冲突检测只检查真正落在当前周次的课程。

## 数据与规则

- 每个学生账号一份学期设置：`timetable_semester(username, semester_name, start_date, end_date, updated_at)`。
- 每条课程新增 `week_pattern`：`EVERY`（每周）、`ODD`（单周）、`EVEN`（双周）。
- 周次从学期开始日期所在周的周一开始计算，第 1 周为该周；显示周视图时按周一至周日切分。
- 课程是否出现由三个条件共同决定：当天在学期起止范围内、课程星期匹配、课程单双周与当前周次匹配。
- 冲突只在“当前显示周次内实际会出现”的课程之间计算。因此单周课与双周课即使占用同一时段，也不会被误判冲突；每周课与单双周课重叠仍会提示。
- 首页“今天上什么”复用同一套过滤逻辑，不再单独写一份判断。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/timetable` | 当前学生课程列表，含 `weekPattern` |
| `POST` | `/api/timetable` | 新增课程，`weekPattern` 缺省为 `EVERY` |
| `PUT` | `/api/timetable/{id}` | 修改课程，仍校验归属 |
| `DELETE` | `/api/timetable/{id}` | 删除课程，仍校验归属 |
| `GET` | `/api/timetable/semester` | 当前学生学期；未设置时返回空响应体 |
| `PUT` | `/api/timetable/semester` | 保存学期名称、开始日期、结束日期 |

所有接口只允许学生角色；写操作需要 CSRF。学期结束日期不得早于开始日期，最长 400 天；课程周次只接受 `EVERY/ODD/EVEN`。

## GitHub 项目调研（10 个）

以下项目用于借鉴信息架构、周次表达和冲突规则，**没有复制其代码**。仓库链接按调研时看到的项目页面记录。

1. [layzer/ManualSchoolTimetable](https://github.com/layzer/ManualSchoolTimetable)
   - 观察到：支持单双周排课；同一时段排入单周与双周课程，因为周次错开不判冲突；每周课程与单双周课程重叠则判冲突。
   - 采用：`week_pattern` 三态，冲突只比较当前周次实际出现的课程。

2. [elliott-json-park/obsidian-class-timetable](https://github.com/elliott-json-park/obsidian-class-timetable)
   - 观察到：`odd` / `even` 隔周课程；设置学期结束后停止绘制课程；还支持无课日。
   - 采用：学期结束日期作为硬边界，单双周按周次计算，而不是按自然月。

3. [WyLAskTg/ClassPilot](https://github.com/WyLAskTg/ClassPilot)
   - 观察到：多学期管理、重复规则、当前时间线和冲突提示。
   - 采用：保留当前时间线，并把学期信息放到课表页显眼位置；暂不引入多学期归档。

4. [Whippap/soaring-schedule-remake](https://github.com/Whippap/soaring-schedule-remake)
   - 观察到：周视图课程块、周切换/返回本周、点击详情弹窗。
   - 采用：已有周视图继续沿用“上一周 / 本周 / 下一周”和块级编辑。

5. [lorien123/harmonyos-class-schedule](https://github.com/lorien123/harmonyos-class-schedule)
   - 观察到：HarmonyOS + Spring Boot 前后端分离，课程按账号和课表分享。
   - 采用：课程与学期都应服务端持久化、按账号隔离，不用浏览器本地假数据。

6. [AmanVerma1067/StudySync](https://github.com/AmanVerma1067/StudySync)
   - 观察到：周课表、学术日历、单双学期切换、前后周切换。
   - 采用：把“学期第几周”直接显示在周视图标题下方，降低用户理解单双周的成本。

7. [huishingcheung/Keshu](https://github.com/huishingcheung/Keshu)
   - 观察到：多周课表导入包含独立的开始周和结束周字段，并修正多周导入。
   - 采用：把“周次规则”建模为课程自身属性；当前版本先做每周/单周/双周，不一次性做任意起止周。

8. [dibakarsutradhar/schedula](https://github.com/dibakarsutradhar/schedula)
   - 观察到：学期包含名称、开始/结束日期、教学周、考试周等。
   - 采用：先落地名称和起止日期；教学周/考试周作为后续扩展，不把它们塞进当前 UI。

9. [inannan423/classCrawl](https://github.com/inannan423/classCrawl)
   - 观察到：强智教务课表数据中 `sjbz` 字段，1 表示单周、2 表示双周。
   - 采用：使用稳定枚举值 `ODD/EVEN`，显示层再转成“单周/双周”，避免把教务系统原值直接泄漏到前端。

10. [bhuvanesh-sudo/timetable-scheduler](https://github.com/bhuvanesh-sudo/timetable-scheduler)
    - 观察到：约束式排课、教师工作量、教室容量、连续实验和冲突消除。
    - 采用：冲突检测先限定在“同一周次、同一天、时间重叠”的课程；不做全量排课求解，也不伪造自动优化结果。

## 当前边界

- 一个学生账号只维护一份当前学期，没有多学期切换和历史归档。
- 单双周只按学期第 N 周的奇偶判断；不支持自定义周序列、单双周之外的“三周一休”等规则。
- 课程仍然是每周固定星期和时间，不支持同门课一周多次、分段上课或临时调课。
- 冲突是提示而非拦截，用户仍可保存冲突课程。
- 节假日、考试周停课未进入本轮数据模型。

## 验证

- 后端：`TimetableTest` 6 项，覆盖课程增删改查、越权、CSRF、学期读写、非法日期、非法周次和维护者拒绝。
- 前端：`pnpm build` 通过。
- 浏览器实测：第 13 周单周课显示、双周课隐藏；第 14 周双周课显示、单周课隐藏；两门课都不会在当前周次误报冲突。测试课程已删除，演示数据恢复为 6 门预置课。
